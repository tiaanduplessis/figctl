# Support

Start with the [README](README.md) and the [documentation index](docs/index.md).
Search existing issues before opening a new one.

For a reproducible product problem, use the [bug report form](https://github.com/tiaanduplessis/figctl/issues/new?template=bug_report.yml).
For a proposed change, use the [feature request form](https://github.com/tiaanduplessis/figctl/issues/new?template=feature_request.yml).

Remove Figma tokens, private file keys, screenshots, and other sensitive data
from reports. Use [SECURITY.md](SECURITY.md) and the private security reporting
form for vulnerabilities.
