# Code of Conduct

The figctl project is committed to a respectful, inclusive, and harassment-free
community for everyone who participates in issues, pull requests, reviews, and
other project spaces.

Expected behavior includes:

- using welcoming and professional language;
- respecting different viewpoints and experience levels;
- accepting constructive feedback; and
- focusing on what is best for the project and its users.

Unacceptable behavior includes harassment, discrimination, personal attacks,
unwanted sexual attention, publishing private information, and disruptive
conduct in project spaces.

Report conduct concerns privately to the repository owner through the contact
options on the [maintainer's GitHub profile](https://github.com/tiaanduplessis).
Report security vulnerabilities using [SECURITY.md](SECURITY.md).

The maintainer will review reports and may remove comments, close issues, or
restrict participation when needed to keep project spaces safe and useful.
